# Brand

One mark, in SVG and two raster sizes.

`logo.svg` is the primary asset and the only one that should be edited. The
PNGs are rendered from it.

## The mark

An artificial horizon.

The instrument a pilot reads to know which way is up is called an artificial
horizon. The chart this product is built around is called the expiry horizon.
The two names were arrived at independently, which means the mark can be
literal rather than being another glowing shield in a category full of them.

- The horizon sits **below centre**, because the near half of the chart is the
  half that matters
- The graduations close up towards the left, the way a logarithmic axis does
- The single red mark is an authority near expiry. It is the only warm colour
  in the mark, which is the rule the console follows: colour means severity and
  nothing else

Sized so the circle, the horizon and the one mark still read at 16px. The
graduations are the first thing to disappear and are meant to be.

## Colour

| | |
|:--|:--|
| `#0a7ea4` | Signal — the instrument, and anything interactive |
| `#d93025` | Critical — severity only, never decoration |

Both chosen to hold on a white page and on a near-black one, so a single file
serves light and dark rather than needing a pair.

## Using it

Prefer `logo.svg`. Use `logo-512.png` where a raster is required — an
organisation avatar, a social card — and `logo-128.png` for anything small.
